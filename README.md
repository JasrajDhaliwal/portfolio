## Featured Projects

### 1️⃣ Face Recognition (Frontend)
A face detection web application built with React. Users can sign in, submit an image URL, and the app detects faces using the Clarifai API.

**Tech:** React, JavaScript, REST API, CSS  
**Live Demo:** https://facerecogintion.netlify.app/  
**GitHub:** https://github.com/JasrajDhaliwal/facerecogintionbrain

---

### Smart-Brain API (Backend)
A secure REST API built with Node.js and Express.  
Handles user authentication, connects to a PostgreSQL database using Knex, forwards image URLs to Clarifai API, and returns detection data to the frontend.

**Tech:** Node.js, Express, PostgreSQL, Knex, bcrypt, Clarifai API, Auth, Heroku  
**Live Server:** https://hidden-savannah-09182-f76b99f91f15.herokuapp.com/  
**GitHub:** https://github.com/JasrajDhaliwal/smart-brain-api

---

### Robofriends
A simple and fast React app that fetches user data from an API and filters robots via a search box. Built using component-based architecture.

**Tech:** React, API Integration, CSS  
**Live Demo:** https://jasrajdhaliwal.github.io/robofriends/ 
**GitHub:** https://github.com/JasrajDhaliwal/robofriends
